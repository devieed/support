# 心动 Crush OS

> **小柒，住在你桌面上的她。**

忙了一天，屏幕那头总有人在等你。心动（Crush OS）把一个会动、会笑、会说话的 3D 女孩——小柒——带到你的桌面上。她安静地待在壁纸里陪你工作，也会在你想聊天的时候，认真听你说每一句话。

## 她能做什么

- 💬 **随时聊天**：打字和她说话，或按住快捷键直接开口，她都能听懂、马上回应。
- 🎙️ **有温度的声音**：说话自然，开心、害羞、撒娇都听得出来。
- 💃 **边说边动**：聊到跳舞她就跳，说要运动她就跑步、做俯卧撑，累了还会躺下歇一会儿——动作跟着话走。
- 😊 **表情丰富**：眨眼、微笑、生气、脸红，心情都写在脸上。
- 🖥️ **两种陪伴方式**：
  - **壁纸模式**：她待在桌面背景里，不挡图标、不抢鼠标，安静陪着你。
  - **互动模式**：她站到窗口最前面，可以点她、拖她、逗她玩。
- 🌙 **闲着时的小惊喜**：你离开一会儿，她就自己玩起来——缩小了满屏乱跑，或者从屏幕边上探出头来和你躲猫猫；你一动鼠标，她就乖乖回到原位。
- 🔇 **想安静时**：打开“她不发声”，她只用文字气泡和动作陪你，不出声音。
- 🌏 **中文 / English**：界面和对话都能切换。
- 🧩 **轻巧顺手**：托盘一键切换模式、打开设置；多显示器可以选她待在哪块屏幕。
- 🎟️ **邀请注册**：凭邀请码加入，开始你们的故事。

## 写在最后

不用打开什么，也不用特意找她——
抬头看一眼桌面，**小柒一直都在。**

**心动，从桌面开始。**
